# Cuánto Cuesta Cartagena

What taxi rides actually cost in Cartagena, reported by the people who paid them.

Next.js (App Router) + TypeScript + Tailwind, static-first, deployed on Vercel. See `CLAUDE.md` for the project's non-negotiable rules and constraints.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
